Dejar la fuerza de voluntad → juntar **evidencia** de la nueva identidad.
1. Decide quién eres (cada acción = un voto).
2. Junta evidencia, no frases (barra baja, repo = pruebas).
3. Sé científica, no jueza (tropiezo = data).
4. Re-encuadra la incomodidad (señal de crecimiento).
5. Vive en presente (solo el voto de hoy).
